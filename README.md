# luci-plot

A lightweight, dependency-free SVG plotting library intended for OpenWrt LuCI.

> **Development status**
>
> This project is currently experimental and under active development.
> The API and internal structure are not considered stable and may change
> significantly.
>
> The current code is primarily a working prototype for experimenting with
> a generic plotting interface. Feedback, ideas and suggestions regarding
> the design are very welcome.

## Motivation

The project started while experimenting with the SVG chart implementation
used in the LuCI LibreSpeed work.

The basic plotting approach was useful, but the goal of `luci-plot` is to
separate plotting from application-specific data structures and data sources.

The plotter therefore operates on generic numeric data and does not know
anything about LibreSpeed, RRD or any particular application.

## Current features

- Dependency-free SVG rendering
- JSON-compatible declarative plot configuration
- Index-based X axes
- Time-based X axes
- Arbitrary numeric X axes
- Irregularly spaced X values
- Multiple data series
- Optional min/max bands
- Up to two independent Y axes
- Automatic or fixed Y-axis ranges
- Nearest-data-point hover
- Configurable value formatting
- Named JSON-compatible formatters
- Missing values create gaps instead of connecting across them
- Responsive SVG rendering
- No dependency on a particular data source

## Declarative interface

The primary interface can be described entirely using JSON-compatible
objects. Plot configuration and data can therefore be generated by a
backend and passed directly to the renderer.

For example:

    {
        "plot": {
            "x": {
                "key": "time",
                "type": "time",
                "label": "Time"
            },

            "axes": {
                "temperature": {
                    "position": "left",
                    "unit": "°C",
                    "min": 0,
                    "max": 100
                },

                "humidity": {
                    "position": "right",
                    "unit": "%"
                }
            },

            "series": [
                {
                    "key": "temperature",
                    "label": "Temperature",
                    "axis": "temperature",
                    "format": "number"
                },

                {
                    "key": "humidity",
                    "label": "Humidity",
                    "axis": "humidity",
                    "format": "integer"
                }
            ]
        },

        "data": [
            {
                "time": 1788498000,
                "temperature": 21.3,
                "humidity": 57
            },

            {
                "time": 1788498060,
                "temperature": 21.5,
                "humidity": 56
            }
        ]
    }

It can be rendered directly:

    const spec = await response.json();
    LuciPlot.render('#plot', spec);

The original JavaScript interface remains available and may use functions
for custom accessors and formatters where required.

## Axes

X axes may use index, numeric or time values.

Y series may be assigned to independent named axes. Up to two Y axes are
currently supported, typically positioned on the left and right side.

Y-axis limits may be determined automatically or constrained explicitly:

    "axes": {
        "percent": {
            "position": "right",
            "unit": "%",
            "min": 0,
            "max": 100
        }
    }

`min` and `max` may also be specified independently. An unspecified bound
is calculated automatically from the data.

## Formatting

The declarative interface currently provides the following named formatters:

- `number`
- `integer`
- `time`
- `date`
- `datetime`

The extended JavaScript interface may additionally use formatter functions.

## Missing values

Missing or non-finite values are not plotted.

This includes `null`, `undefined`, non-finite numeric values and common
NaN representations. Missing values in a series create a gap in the line
rather than connecting the surrounding points.

A data point with an invalid X value is ignored completely.

## Data sources

`luci-plot` deliberately does not contain data-source-specific code.

A backend may obtain data from RRD, a database, sensors or any other source
and transform it into the neutral JSON-compatible representation expected
by the plotter.

For the intended RRD use case, the current approach is:

    RRD
     |
     | rrdtool xport --json
     v
    CGI / backend
     |
     | generic luci-plot JSON
     v
    luci-plot
     |
     v
    SVG

RRD-specific processing therefore remains outside both the plotting library
and the browser-side application.

## Example

A minimal numeric plot can also be created using the JavaScript interface:

    LuciPlot.render('#plot', data, {
        x: {
            key: 'rpm',
            type: 'number',
            label: 'RPM'
        },

        series: [
            {
                key: 'temperature',
                label: 'Temperature',
                unit: '°C',
                digits: 1
            }
        ]
    });

See `example/index.html` for a more complete example.
or
See `API.md` for a description of the available interfaces.

## Origin

The initial implementation was inspired by the SVG chart implementation
in the LuCI LibreSpeed work by BKPepe / OpenWrt LuCI.

The code has since been generalized to be independent of LibreSpeed and
specific data sources.
